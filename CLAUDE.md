# WebDark Otimizador

Otimizador para Windows: Python (pywebview) + interface HTML em `web/`.

## Mapa do código: leia antes de abrir o código
O vault do Obsidian em `Otimizador/` diz onde fica cada coisa. Comece por `Otimizador/00 Índice.md`, vá até a nota da tela ou do módulo e abra só os arquivos e funções que ela indica. Não leia o projeto inteiro.

- `Otimizador/Arquitetura.md`: como JS e Python conversam (Api, eventos, OWNER, abas)
- `Otimizador/Receitas.md`: passo a passo para mudanças comuns
- `Otimizador/Legado.md`: arquivos antigos (Tk) que não fazem parte do app; não mexer

## Manter o mapa em dia
Ao criar, renomear ou mover uma tela, aba, arquivo, método público da `Api` ou evento, atualize a nota correspondente em `Otimizador/` na mesma mudança.
